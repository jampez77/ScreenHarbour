# ScreenHarbour 0.2.55 — prerelease

Returning from a movie restores the selected Home item to the position it occupied on screen when opened. Saving only the scrolling containers’ offsets was not enough when Jellyfin changed the layout or replaced a scrolling container while the item’s details were open.

Home now also remembers the item’s viewport position. Restoration finds its current scrolling containers and corrects movement caused by delayed native scrolling or layout updates. This follows the actual changes instead of relying on one correction after a fixed delay, which could occur too early on a slower TV.

The originating row and tab, selected item, shuffle order and loaded artwork are retained. Left/Right navigation can immediately select another item without having its horizontal position pulled back; leaving the row, pointer input and manual scrolling remain responsive. Fresh Home visits still reshuffle enabled rows.

All saved rows, settings, seasonal effects and manual ordering are preserved. No reconfiguration or settings migration is required.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload browsers or close and reopen web-based TV clients. Keep **File Transformation** enabled.

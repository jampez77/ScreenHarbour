# ScreenHarbour 0.2.52 — prerelease

Open **Settings → ScreenHarbour → Collection rows** in desktop display mode to configure your Home rows. The editor now sits alongside **Streaming services** and **Loading screen**, and the Collections page keeps its browsing controls. If you have renamed the interface, your configured title replaces ScreenHarbour in the Settings section heading.

The same editor still provides collection choices, tabs, manual item order, ranking, Home position, Watchlist rows, seasonal groups, themed appearance and live previews. Editing remains desktop-only; TV continues to display the saved account rows without an editing control.

All existing rows and settings remain unchanged. No reconfiguration or settings migration is required.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload browsers or close and reopen web-based TV clients. Keep **File Transformation** enabled.

# ScreenHarbour 0.2.50 — prerelease

Fixes seasonal rows bouncing up and down when moving Left/Right on TV. Jellyfin’s native scroll manager schedules its own focus-centering animation after a card receives focus. That movement competed with ScreenHarbour’s seasonal-row alignment, even when CSS smooth scrolling was temporarily disabled.

Seasonal card scrollers now use Jellyfin’s existing custom-scroll contract on both axes. ScreenHarbour keeps the selected item visible and positions the row without the delayed native animation pulling it away again. Other Jellyfin scrollers keep their existing behavior.

Left/Right movement adjusts only the horizontal position. Entering or leaving a seasonal row gets one bounded final visibility check after any earlier native animation finishes. It does not restart on each horizontal keypress, follow an abandoned selection or survive leaving the page.

The previous release’s checks covered CSS smooth scrolling but missed Jellyfin’s JavaScript scroll animation. This release adds regressions using the Jellyfin 12 scroll manager to exercise that interaction.

All saved settings, row positions, seasonal dates, expansion choices, themed headings, frames, doors, ranks, shuffle choices, local fonts and smaller lazy-loaded TV images are preserved. No configuration changes are needed.

# ScreenHarbour 0.2.53 — prerelease

Opening a film from a shuffled Home row and returning with Back now keeps the current item order. The selected card returns to the same place in the originating row, including when that film appears in several Home rows.

A fresh Home visit still reshuffles rows with **Shuffle on load** enabled. Background refreshes keep the current visit’s order stable. Saved manual ordering, collection membership, seasonal settings and the shuffle preference itself are unchanged. No reconfiguration or settings migration is required.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload browsers or close and reopen web-based TV clients. Keep **File Transformation** enabled.

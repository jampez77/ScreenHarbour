# ScreenHarbour 0.2.54 — prerelease

Back to Home now makes one final position correction after Jellyfin’s delayed native focus scrolling finishes. That queued animation could otherwise move the page after ScreenHarbour had restored the selected card. The correction preserves the originating row and tab, current shuffle and loaded artwork. It does not refocus another card, and new navigation, pointer input or wheel scrolling takes priority.

Seasonal parallax now has **three times the movement range**: 13.5% of the row width from one end to the other, previously 4.5%. It uses the same existing background image and 115%-wide scenery surface, with safe overlap at both ends. No additional images or graphics layers are added. Updates remain limited to one transform per animation frame, and reduced-motion preferences keep the background still.

Fresh Home visits still reshuffle enabled rows. All saved rows, settings, seasonal effects and manual ordering are preserved. No reconfiguration or settings migration is required.

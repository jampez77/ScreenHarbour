# ScreenHarbour 0.2.48 — prerelease

Seasonal rows have an optional **Full screen** setting under **Appearance → Height when focused**. Focusing an item expands the row into the space beneath Jellyfin’s header and transforms its heading into larger themed lettering. Each of the seven Halloween/Christmas scenery styles has its own locally bundled font, including horror lettering for Nightmare. Posters keep their normal size; leaving the row restores its ordinary height and title. Up/Down continues through Home normally. The editor shows a scaled preview, and reduced-motion preferences remain respected.

TV navigation avoids repeated Home discovery and placement work when focus moves between seasonal cards. Saved scroll positions reuse existing row references until Home changes. Horizontal navigation inspects the current row, and door reveals update only the previously and newly selected cards. Parallax moves one clipped scenery layer instead of repainting the background position on every scroll frame; the additional graphics layers are released when the row loses focus.

A 60-card browser fixture previously performed 55 native-row discoveries, 24 Home reattachments and 12 complete navigation-row scans during twelve horizontal moves. The updated code performs none of those repeated scans. These are controlled browser measurements, not a measured frame-rate improvement on an LG television.

Existing settings, seasonal dates, row positions, doors, frames, ranking, shuffle and the smaller lazy-loaded TV images are preserved. Full-screen expansion is opt-in. Clients predating this feature can read the rows but cannot silently erase a saved full-screen appearance. Font files are served locally and cached; only the selected style downloads. Their SIL Open Font License notices and provenance are included in each package.
